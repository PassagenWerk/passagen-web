# Web 应用能力

**状态：已完成并持续维护**

Passagen Web 当前提供：

- 带本地 library lock 的 FastAPI 和 React packaged application。
- Paper 搜索、状态筛选、多 Tag 筛选、排序、分页和 URL state。
- Cleaned/original Abstract、结构化 Summary、Outline 和 PDF evidence navigation。
- 用户 metadata 编辑、全局 Tag、上下文 Tag 分配和有序 Collection。
- PDF 上传、pending paper 处理、持久化 run、进度、失败和重试。
- 全局 processing status 和上下文逐阶段 reprocess 控件。
- 响应式布局、Light/Dark Mode、键盘导航和阅读字号偏好。
- Origin validation、artifact validation、PDF byte range 和 SPA fallback。

当前用户行为见仓库 README 和用户运行指南。
